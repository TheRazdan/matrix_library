## 📚 Математические основы

### Определение матрицы

**Матрица** — это прямоугольная таблица чисел, организованная в строки и столбцы. Матрица размером *m × n* содержит *m* строк и *n* столбцов.

Пример матрицы 2×3:
```
[ 1  2  3 ]
[ 4  5  6 ]
```

Элемент матрицы обозначается как a[i][j], где *i* — номер строки, *j* — номер столбца (обычно нумерация начинается с 0 или 1).

### Типы матриц

| Тип | Описание | Пример |
|-----|---------|---------|
| **Нулевая матрица** | Все элементы равны 0 | [[0, 0], [0, 0]] |
| **Единичная матрица** | На диагонали 1, остальное 0 | [[1, 0], [0, 1]] |
| **Диагональная матрица** | Ненулевые элементы только на диагонали | [[2, 0], [0, 3]] |
| **Симметричная матрица** | A = A<sup>T</sup> (равна своей транспонированной) | [[1, 2], [2, 3]] |
| **Верхняя треугольная** | Все элементы ниже диагонали — 0 | [[1, 2], [0, 3]] |
| **Нижняя треугольная** | Все элементы выше диагонали — 0 | [[1, 0], [2, 3]] |

### Основные операции над матрицами

#### 1. **Сложение и вычитание матриц**

Матрицы одинакового размера складываются поэлементно:
```
A + B: c[i][j] = a[i][j] + b[i][j]
```

**Пример:**
```
[ 1  2 ]   [ 5  6 ]   [ 6  8 ]
[ 3  4 ] + [ 7  8 ] = [ 10 12 ]
```

#### 2. **Умножение матрицы на скаляр**

Каждый элемент матрицы умножается на число:
```
k * A: c[i][j] = k * a[i][j]
```

#### 3. **Умножение матриц**

Результат умножения матриц A (размер m×k) и B (размер k×n) — матрица C (размер m×n):
```
c[i][j] = sum(a[i][t] * b[t][j]) для t от 0 до k-1
```

**Важно:** Матрицу A можно умножить на матрицу B только если количество столбцов A равно количеству строк B.

**Пример:**
```
[ 1  2 ]   [ 5  6 ]   [ 1*5 + 2*7   1*6 + 2*8 ]   [ 19  22 ]
[ 3  4 ] * [ 7  8 ] = [ 3*5 + 4*7   3*6 + 4*8 ] = [ 43  50 ]
```

#### 4. **Транспонирование**

Строки и столбцы матрицы меняются местами:
```
B = A^T: b[j][i] = a[i][j]
```

**Пример:**
```
[ 1  2  3 ]^T     [ 1  4 ]
[ 4  5  6 ]   =   [ 2  5 ]
                  [ 3  6 ]
```

#### 5. **Ранг матрицы**

Ранг матрицы — это максимальное количество линейно независимых строк (или столбцов).

**Свойства:**
- Для матрицы m×n: ранг ≤ min(m, n)
- Ранг единичной матрицы = её размер
- Если ранг < min(m, n), матрица вырожденная

#### 6. **След матрицы (Trace)**

След квадратной матрицы — это сумма диагональных элементов:
```
tr(A) = sum(a[i][i])
```

### Применение матриц

- **Компьютерная графика:** трансформации объектов (масштабирование, поворот, сдвиг)
- **Системы линейных уравнений:** решение через матрицы
- **Машинное обучение:** представление данных и весов нейросетей
- **Сетевые потоки:** матрицы смежности графов
- **Физика:** преобразования координат и векторных операций

- **`is_symmetric`**: Определяет, симметрична ли матрица относительно главной диагонали (симметрия достигается, если $A = A^T$).

Эти функции предоставляют удобные инструменты для анализа свойств матриц, полезные при выполнении сложных математических задач и разработке приложений, работающих с матричными данными.

### Модуль 1: Создание и инициализация матриц

#### `create_matrix(rows: int, cols: int, default_value: float = 0) -> list[list[float]]`

**Описание:** Создаёт матрицу размера rows × cols, заполненную значением `default_value`.

**Параметры:**
- `rows` (int) — количество строк
- `cols` (int) — количество столбцов
- `default_value` (float) — значение для заполнения (по умолчанию 0)

**Возвращаемое значение:** Список списков представляющий матрицу

**Исключения:**
- `ValueError` если rows ≤ 0 или cols ≤ 0

**Пример:**
```python
m = create_matrix(2, 3, 5)
# [[5, 5, 5], [5, 5, 5]]
```

---

#### `create_identity_matrix(n: int) -> list[list[float]]`

**Описание:** Создаёт единичную матрицу размера n × n (на диагонали 1, остальное 0).

**Параметры:**
- `n` (int) — размер матрицы

**Возвращаемое значение:** Единичная матрица

**Исключения:**
- `ValueError` если n ≤ 0

**Пример:**
```python
m = create_identity_matrix(3)
# [[1, 0, 0], [0, 1, 0], [0, 0, 1]]
```

---

#### `create_zero_matrix(rows: int, cols: int) -> list[list[float]]`

**Описание:** Создаёт нулевую матрицу размера rows × cols.

**Параметры:**
- `rows` (int) — количество строк
- `cols` (int) — количество столбцов

**Возвращаемое значение:** Нулевая матрица

**Исключения:**
- `ValueError` если rows ≤ 0 или cols ≤ 0

**Пример:**
```python
m = create_zero_matrix(2, 2)
# [[0, 0], [0, 0]]
```

---

#### `create_random_matrix(rows: int, cols: int, min_val: float, max_val: float) -> list[list[float]]`

**Описание:** Создаёт матрицу со случайными значениями в диапазоне [min_val, max_val].

**Параметры:**
- `rows` (int) — количество строк
- `cols` (int) — количество столбцов
- `min_val` (float) — минимальное значение
- `max_val` (float) — максимальное значение

**Возвращаемое значение:** Матрица со случайными значениями

**Исключения:**
- `ValueError` если rows ≤ 0, cols ≤ 0 или min_val > max_val

**Пример:**
```python
m = create_random_matrix(2, 2, 1, 10)
# [[7, 3], [9, 2]]  # результат будет разным
```

---

#### `create_matrix_from_list(data: list[list[float]]) -> list[list[float]]`

**Описание:** Создаёт матрицу из списка списков с проверкой корректности.

**Параметры:**
- `data` (list[list[float]]) — список списков

**Возвращаемое значение:** Матрица

**Исключения:**
- `ValueError` если данные не являются матрицей (разное количество столбцов в строках)
- `ValueError` если data пуста

**Пример:**
```python
m = create_matrix_from_list([[1, 2], [3, 4]])
# [[1, 2], [3, 4]]
```

### Модуль 3: Арифметические операции

#### `add_matrices(matrix1: list[list[float]], matrix2: list[list[float]]) -> list[list[float]]`

**Описание:** Складывает две матрицы одинакового размера.

```python
def transpose(matrix: list[list[float]]) -> list[list[float]]:
    """
    Transpose a matrix (swap rows and columns).
    
    Args:
        matrix: Input matrix as a list of lists.
    
    Returns:
        Transposed matrix where rows become columns.
    
    Raises:
        ValueError: If matrix is empty.
    
    Example:
        >>> m = [[1, 2, 3], [4, 5, 6]]
        >>> transpose(m)
        [[1, 4], [2, 5], [3, 6]]
    """
    if not matrix or not matrix[0]:
        raise ValueError("Matrix cannot be empty")
    
    rows = len(matrix)
    cols = len(matrix[0])
    
    # Validate all rows have same length
    for row in matrix:
        if len(row) != cols:
            raise ValueError("All rows must have the same number of columns")
    
    # Create transposed matrix
    transposed = [[matrix[i][j] for i in range(rows)] for j in range(cols)]
    
    return transposed
```
